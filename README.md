
# Shortest Path Finder Using Dijkstra's Algorithm

## Project Overview
This ADSAA mini-project finds the shortest path between two locations using Dijkstra's Algorithm.

## Objectives
- Find the shortest route between two locations.
- Calculate the minimum total distance.
- Understand weighted graphs and Greedy Algorithms.

## Technologies Used
- Python 3
- Dijkstra's Algorithm
- Graph Data Structure
- Priority Queue

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the command:

   python main.py

4. Enter the starting location.
5. Enter the destination.

## Sample Output
Shortest path: A -> C -> B -> D
Total distance: 8 km

- GPS navigation
